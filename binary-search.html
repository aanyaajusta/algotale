Binary Search

Binary search finds a target in a sorted list. It checks the middle element, then throws away the half that cannot contain the target. Each step halves the search space, so the time complexity is O(log n). 

def binary_search(arr, target):
    low, high = 0, len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1
